# 🤖 AI Text Summarizer with Gradio

An interactive AI-powered text summarization application built with **Python, Gradio, Requests, and OpenRouter API**.

The application receives text from the user, sends it to an AI model through an OpenAI-compatible API endpoint, and displays the generated summary through a simple web interface.

## ✨ Features

- 📝 Text input using Gradio
- 🔐 Password-protected API Key input
- 🤖 AI-powered text summarization
- 🌐 OpenRouter API integration
- 📡 HTTP POST requests using Requests
- ✅ Basic input validation
- ⚠️ Simple API error handling
- 🖥️ Local web interface with Gradio

## 🛠️ Technologies

- Python
- Gradio
- Requests
- OpenRouter API
- Jupyter Notebook / Google Colab
